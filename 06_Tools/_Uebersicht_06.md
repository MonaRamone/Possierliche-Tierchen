# Toolbox – Übersicht

## Prinzip
Eine Technik pro Datei, wiederverwendbar über mehrere Situationen und Archetypen hinweg. Nicht an eine bestimmte Person gebunden, sondern an eine Art von Situation.

---
## Techniken
| Technik | Prinzip in einem Satz |
|---|---|
| [[Kaputte Platte]] | Ein fester Satz, wortgleich wiederholt, unabhängig vom Gegenargument. |
| [[Fogging]] | Kritik neutral/teilweise zustimmen, ohne inhaltlich einzusteigen. |
| [[Nachfragetechnik]] | Wiederholt neutral nachfragen, statt sich zu rechtfertigen. |
| [[Verzoegerung]] | Nicht sofort reagieren, Zeit gewinnen vor einer Zusage. |
| [[Die Rueckfrage]] | Erklärlast an die andere Person zurückgeben. |
| [[Verantwortung zurueckgeben]] | Entscheidung/Bewertung bei der zuständigen Person belassen. |
| [[DEAR MAN]] | DBT-Skill: ein Anliegen durchsetzen, ohne die Beziehung zu belasten. |
| [[GIVE]] | DBT-Skill: Beziehung erhalten, wenn sie wichtiger ist als das Durchsetzen. |
| [[FAST]] | DBT-Skill: Selbstachtung wahren, wenn Druck besteht nachzugeben. |
| [[Grey Rock]] | Bewusst emotionslos werden, keine Angriffsfläche liefern. |
