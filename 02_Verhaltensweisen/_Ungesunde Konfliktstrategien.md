_Welche Strategien verwenden Menschen, wenn sie mit Konflikten, Unsicherheit oder Bedürfnissen nicht konstruktiv umgehen?_

| Verhaltensweise          | Konfliktstrategie              |
| ------------------------ | ------------------------------ |
| Good girl/boy            | Anpassung                      |
| Beleidigte Leberwurst    | Rückzug                        |
| Wurst/Warmduscher        | Indirekter Widerstand          |
| Pavianarsch              | Angriff                        |
| Master of Puppets        | Verdeckte Kontrolle            |
| Jakob, der Lügner        | Ausweichen                     |
| Kommste heut nicht...    | Vermeidung                     |
| Haar in der Suppe        | Kritik                         |
| Attention Bitch          | Aufmerksamkeit                 |
| Angeber                  | Status                         |
| Die tote Ziege           | Abwertung durch Vergleich      |
| I'm walking on eggshells | Überempfindlichkeit            |
| Probleme wegnehmen       | Opferrolle bzw. Problembindung |
| Ruf! Mich! An!           | Dominanz                       |
| Stromberg                | Abwertung                      |

- Jede Verhaltensweise beschreibt eine mögliche Strategie, mit Konflikten, Unsicherheit oder eigenen Bedürfnissen umzugehen.
- Diese Strategien entstehen häufig aus nachvollziehbaren Erfahrungen und können kurzfristig funktionieren.
- Langfristig führen sie jedoch oft dazu, dass Konflikte nicht gelöst, sondern verschoben, verstärkt oder wiederholt werden.
---

Wenn man sie sortiert, sieht man verschiedene "Werkzeugkästen" für den Umgang mit Konflikten:

- **Abwertung:** Stromberg
- **Angriff:** Pavianarsch
- **Kontrolle:** Ruf! Mich! An!, Master of Puppets
- **Rückzug:** Beleidigte Leberwurst, Kommste heut nicht...
- **Anpassung:** Good girl/boy
- **Verdeckung:** Jakob, der Lügner, Wurst/Warmduscher
- **Status:** Angeber
- **Aufmerksamkeit:** Attention Bitch
- **Vergleich:** Die tote Ziege
- **Kritik:** Haar in der Suppe
- **Problembindung:** Was bleibt diesem Menschen, wenn du ihm seine Probleme wegnimmst?
- **Kränkbarkeit:** I'm walking on eggshells
