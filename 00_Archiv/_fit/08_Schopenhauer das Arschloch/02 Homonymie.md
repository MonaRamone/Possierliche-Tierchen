# 2. Homonymie

## Kerndefinition
Ein Wort in einer anderen Bedeutung verwenden, als der Gegner es gemeint hat.

## Gegenmittel
Begriff explizit definieren, bevor man weiterdiskutiert: "Ich meinte X im Sinne von..." Verhindert, dass die Verschiebung unbemerkt bleibt.
